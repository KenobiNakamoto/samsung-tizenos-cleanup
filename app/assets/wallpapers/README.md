# Launcher wallpapers

The fifteen entries in `SOURCES.json` each have a background JPEG, a thumbnail and a small blurred panel backdrop. Four registered material JPEGs per image live in `../materials/`. All derived images retain the source photograph's terms.

Photo pages, authors and licence observations are in [asset sources](../../../docs/asset-sources.md). Generation instructions are in [asset generation](https://github.com/nthnclrk/CleanFrame/blob/fa537d1892b71d2de2bf94c24cbff3812e9f70d5/docs/assets.md). Full-size originals remain outside the repository.
