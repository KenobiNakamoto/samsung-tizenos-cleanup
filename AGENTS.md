# Agent handoff

Read README.md, GUIDE.md, docs/compatibility.md and docs/validation.md before changing this project. Source work does not authorize a connection to a TV. Ask for/establish the exact owner-authorized device task and use that device’s fresh baseline.

This public repo has no household backups, certificates or current LAN identity. Do not invent them. The original core cleanup passed cold boot; extended cleanup has a Gaming Hub holdout and seven runtime-only masks. Permanent root was not implemented. Treat those as historical reference-device results, not facts about a new user’s TV.

Use the private memory workflow in memory/README.md. Search prior sources before repeating research. Log nonsecret commands, touched files, times, exit codes and evidence. Distinguish instructions issued from actions observed. Do not put secrets in logs or commits. Check .gitignore and the staged tree, not only current untracked files.

Retain CleanFrame credits, public font licenses and remote interaction behavior. Run the checks documented in CONTRIBUTING.md. Never overwrite a native Home baseline or silently replace an installed app identity. Keep TV work single-session and sequential; do not interrupt active root cleanup for a second probe.
